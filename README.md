# cart-pole-RL

## Description

This project explores reinforcement learning in the classic CartPole environment. It trains an agent to balance a pole by moving a cart left or right, comparing learning approaches or experiments and recording the resulting policy performance. 

## Setup

1. Install Python 3.9 or newer.
2. Open a terminal in the project directory and create a virtual environment:

	```bash
	python -m venv .venv
	```

	Activate it on Windows (PowerShell):
	```powershell
	.\.venv\Scripts\Activate.ps1
	```

	Or on macOS/Linux:
	```bash
	source .venv/bin/activate
	```

3. Install the project dependencies.txt`, run:
	```bash
	python -m pip install -r requirements.txt
	```
